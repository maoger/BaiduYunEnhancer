# BaiduYunEnhancer

> ⚠️ **重要提示**：现代百度网盘的下载限制主要由**服务端 + 账号等级（SVIP）**判断，纯客户端伪造 `navigator.platform` **大概率无法恢复下载功能**。
> 本项目仅作为浏览器扩展/油猴脚本注入机制的**技术参考**，请勿期待它能稳定破解下载限制。

## 1. 原理

历史上，百度网盘前端曾根据浏览器的操作系统/硬件平台（`navigator.platform`）决定是否提供直接下载入口。
本脚本据此尝试伪造 `navigator.platform`，使页面误判平台环境，从而尝试绕过下载限制：

* ① 直接使用浏览器或迅雷等下载百度云文件；
* ② 直接下载整个文件夹；
* ③ 选择多个文件一次性批量下载。

> 说明：以上为该思路在历史版本上的预期效果，当前版本不保证仍然有效（见顶部提示）。

## 2. 为什么早期版本失效

早期版本直接在脚本里执行 `Object.defineProperty(navigator,'platform',…)`。但油猴脚本默认运行在**沙箱（isolated world）** 中，改写的只是沙箱内 `navigator` 包装对象，**并未注入页面真实的 `navigator`**，因此页面脚本读取到的仍是真实平台值——这是早期版本失效的主要原因之一。

**v0.6** 修复了这一点：改为在 `document-start` 阶段向页面**注入 `<script>`**，让伪造代码运行在**页面真实上下文**中，并将返回值改为**每次加载随机生成**，避免被固定值黑名单识别。

## 3. 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）浏览器扩展；
2. 安装 [BaiduYunEnhancer](https://openuserjs.org/install/maoger/BaiduYunEnhancer.user.js)，由扩展识别并安装；
3. 访问 `pan.baidu.com` 即自动生效。
